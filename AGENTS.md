# Вход в управление выбранным проектом

`.planning/` управляет проектом, расположенным в родительском `PROJECT_ROOT` вне `.planning/`. Методы и память управления не заменяют исходники и реальные результаты проекта.

Следуй [Meta Policy](entry_point/meta_policy/meta_policy.md) → [Project Policy](entry_point/project_policy.md) → [Entry Point](entry_point/entry_point.md) → [Extract Demand](entry_point/extract_demand/extract_demand.md). Внутренние записи `.planning/` разрешены по умолчанию без отдельного согласия; факты и принятие владельца не выдумывай.
